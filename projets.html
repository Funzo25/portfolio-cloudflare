Infrastructure Erasmus — Malte

Mai à juillet 2026 · 8 semaines

Huit semaines dans un environnement informatique avec une équipe de développeurs. Administration d’un NAS WD MyCloud EX4 ARM sous un ancien Linux/BusyBox et mise en place de services internes.

LinuxBusyBoxNginxOpenSSHSFTPOpenSSLdnsmasqPowerShellBashrsynccronSMBSQLite

Compétences travaillées
Administrer une infrastructure legacy, diagnostiquer les incidents, automatiser et documenter.

Voir les réalisations techniques
  • Administration Linux via SSH : utilisateurs, groupes, permissions, stockage, montages et services. Installation d’Entware/opkg et résolution de problèmes sur une architecture ARM ancienne.
  • Hébergement interne : Nginx, virtual hosts, déploiement d’applications Angular, HTTPS, services et ports. DNS interne avec dnsmasq, domaines internes, configuration des postes Windows et diagnostic HSTS.
  • PKI interne avec OpenSSL : Root CA, certificats TLS RSA 4096 bits, SHA-256 et SAN. Déploiement de l’autorité de certification sur Windows pour le HTTPS interne.
  • Accès distants : OpenSSH plus récent sur un système ancien, SSH sur port dédié, SCP, SFTP, utilisateurs isolés et chroot jail.
  • Automatisation : scripts Bash/PowerShell, déploiement, sauvegardes rsync et cron, logs. Utilisation de Samba/SMB et SQLite.
  • Reverse proxy Nginx et cache pour OpenSky API : CORS, headers HTTP et diagnostic HIT/MISS. Documentation technique, runbook, diagrammes réseau et travail en équipe.
